# 🚀 StreamMatrix v1.3.7 - Activity Feed & Chat Verbesserungen

## ✨ Was ist neu?

### 💎 Bits im Activity Feed
- Bits/Cheers werden jetzt angezeigt
- Gelbes Icon für Bits
- Live-Tracking

### 🎁 Gruppierte Gift Subs
- 5+ Gift Subs werden automatisch gruppiert
- Recipients als schöne Badges
- Intelligente 3-Sekunden-Gruppierung
- Einzelne Subs (<5) bleiben einzeln

### 📜 Intelligenter Chat-Scroll
- Scrollt nur wenn du am Ende bist
- Bleibt an Position beim Lesen
- Wie im echten Twitch Chat
