# StreamMatrix Screenshots

Dieser Ordner enthält Screenshots für die Website.

## Benötigte Screenshots:

1. **dashboard.png** - Hauptansicht des Dashboards mit mehreren Kacheln
2. **settings.png** - Einstellungsseite mit Theme-Auswahl
3. **chat.png** - Chat-Kachel mit Emotes und Nachrichten

## Anleitung:

1. Mache Screenshots von der App (am besten in 1920x1080 oder höher)
2. Benenne sie entsprechend um
3. Speichere sie in diesem Ordner
4. Committe und pushe sie zu GitHub

Die Website lädt die Screenshots automatisch von:
`https://raw.githubusercontent.com/19bounty9317/StreamMatrix/main/screenshots/[dateiname].png`

Falls die Screenshots nicht verfügbar sind, werden Platzhalter angezeigt.
