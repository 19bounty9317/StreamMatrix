**Chat Auto-Scroll funktioniert jetzt zuverlässig**

## 📥 Download

**Windows:**
- [StreamMatrix-Setup-1.4.5.exe](https://github.com/19bounty9317/StreamMatrix/releases/download/v1.4.5/StreamMatrix-Setup-1.4.5.exe)

## 🔧 Installation

1. Lade die `.exe` Datei herunter
2. Führe die Datei aus
3. **Windows SmartScreen Warnung?** → "Weitere Informationen" → "Trotzdem ausführen"
4. Fertig! StreamMatrix ist installiert
