# StreamMatrix

**Die ultimative Twitch-Dashboard-Lösung für Streamer**

StreamMatrix ist eine professionelle Desktop-Anwendung, die Streamern ein umfassendes Dashboard zur Verwaltung ihres Twitch-Kanals bietet.

## Features

### Auto-Update System
- Automatische Update-Prüfung beim Start
- Optionale automatische Installation
- Manuelle Update-Prüfung jederzeit möglich

### Chat & Emotes
- Echtzeit-Chat-Integration
- Twitch-Emotes (Global, Kanal-spezifisch, Subscriber)
- 7TV-Emotes (Global & Kanal)
- BTTV-Emotes (Global & Kanal)
- FFZ-Emotes (Global & Kanal)
- User-Card mit Profil-Infos (Klick auf Username)
- Chat-Moderation (Timeout, Ban, Delete)

### Stream-Management
- Live-Viewer-Statistiken
- Stream-Titel & Kategorie ändern
- Stream-Qualität überwachen (Bitrate, Dropped Frames)
- Follower & Subscriber Tracking
- OBS-Integration für Live-Daten

### Sicherheit
- OAuth 2.0 Authentifizierung
- Sichere Token-Verwaltung
