Datenschutzerklärung

Wichtig: Diese Datenschutzerklärung bezieht sich auf die Website streammatrix.de. Informationen zur Datenverarbeitung in der StreamMatrix Desktop-App finden Sie weiter unten.

1. Datenschutz auf einen Blick

Allgemeine Hinweise

Die folgenden Hinweise geben einen einfachen Überblick darüber, was mit Ihren personenbezogenen Daten passiert, wenn Sie diese Website besuchen. Personenbezogene Daten sind alle Daten, mit denen Sie persönlich identifiziert werden können.

2. Datenerfassung auf dieser Website

Hosting

Diese Website wird auf GitHub Pages gehostet. Der Anbieter ist GitHub Inc., 88 Colin P Kelly Jr St, San Francisco, CA 94107, USA. GitHub kann beim Besuch dieser Website technische Informationen erfassen, einschließlich Ihrer IP-Adresse.

Server-Log-Dateien

GitHub Pages erfasst und speichert automatisch Informationen in Server-Log-Dateien, die Ihr Browser automatisch übermittelt. Dies sind:

  • Browsertyp und Browserversion
  • Verwendetes Betriebssystem
  • Referrer URL
  • Hostname des zugreifenden Rechners
  • Uhrzeit der Serveranfrage
  • IP-Adresse

GitHub API

Diese Website nutzt die GitHub API, um die Anzahl der Downloads anzuzeigen. Dabei werden keine personenbezogenen Daten an GitHub übermittelt.

Google Analytics

Diese Website verwendet Google Analytics, einen Webanalysedienst der Google Ireland Limited ("Google"). Google Analytics verwendet Cookies, die eine Analyse der Benutzung der Website durch Sie ermöglichen.

Verwendete Daten:

  • Anonymisierte IP-Adresse (IP-Anonymisierung aktiviert)
  • Besuchte Seiten und Verweildauer
  • Geräte- und Browserinformationen
  • Herkunft des Traffics (Referrer)
  • Interaktionen (Klicks auf Discord, GitHub, Downloads)

Rechtsgrundlage: Die Datenverarbeitung erfolgt auf Grundlage Ihrer Einwilligung (Art. 6 Abs. 1 lit. a DSGVO). Sie können Ihre Einwilligung jederzeit widerrufen.

Widerspruch und Löschung: Sie können die Speicherung von Cookies durch eine entsprechende Einstellung Ihrer Browser-Software verhindern. Sie können darüber hinaus die Erfassung durch Google Analytics verhindern, indem Sie das Browser-Add-on zur Deaktivierung von Google Analytics installieren: Google Analytics Opt-out

Weitere Informationen zu Google Analytics finden Sie in der Datenschutzerklärung von Google.

3. StreamMatrix Desktop-App

Lokale Datenspeicherung

Die StreamMatrix Desktop-App speichert alle Daten ausschließlich lokal auf Ihrem Computer. Es werden keine Daten an externe Server übermittelt (außer an Twitch für die Stream-Funktionalität).

Gespeicherte Daten in der App

  • Twitch-Zugangsdaten: Werden verschlüsselt lokal gespeichert
  • Einstellungen: Theme, Layout, Kachel-Konfigurationen
  • Stream-Historie: Datum, Dauer, Viewer-Zahlen Ihrer eigenen Streams
  • Chat-Verlauf: Temporär im RAM, wird beim Schließen gelöscht

Twitch-Integration

StreamMatrix nutzt die offizielle Twitch API. Dabei gelten die Datenschutzbestimmungen von Twitch: Twitch Datenschutzerklärung

Keine Datenübermittlung

StreamMatrix übermittelt keine Daten an:

  • Die Entwickler von StreamMatrix
  • Drittanbieter-Dienste (außer Twitch API)
  • Analyse- oder Tracking-Dienste
  • Werbenetzwerke
