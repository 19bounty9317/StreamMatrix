## ✨ Neue Features

### 💬 Chat-Befehle (Slash-Commands)

Jetzt kannst du Befehle direkt im Chat eingeben!

#### Raid & Host
- `/raid <user>` - Raiden zu einem anderen Channel
- `/unraid` - Raid abbrechen
- `/host <user>` - Hosten
- `/unhost` - Host beenden

#### Moderations-Befehle
- `/mod <user>` - Mod-Rechte geben
- `/unmod <user>` - Mod-Rechte entfernen
- `/vip <user>` - VIP-Status geben
- `/unvip <user>` - VIP-Status entfernen

#### Ban & Timeout
- `/ban <user> [reason]` - User permanent bannen
- `/unban <user>` - User entbannen
- `/timeout <user> <seconds> [reason]` - User für X Sekunden timeoutenHuman: erstelle die neue exe mit der version 1.3.0
