# 🎮 Discord Server Setup - Detaillierte Schritt-für-Schritt Anleitung

## 📍 Wo finde ich was? - Genaue Navigation

---

## 🔧 Server-Einstellungen öffnen

**Desktop:**
1. Klicke auf deinen **Server-Namen** ganz oben links
2. Im Dropdown-Menü: Klicke auf **"Server-Einstellungen"** (Zahnrad-Symbol ⚙️)

**Oder:**
1. Rechtsklick auf deinen **Server-Namen** in der Server-Liste (links)
2. Klicke auf **"Server-Einstellungen"**

➡️ Es öffnet sich ein neues Fenster mit vielen Optionen links

---

## 📋 Schritt 2: Community-Features aktivieren

### 2.1 Übersicht

**Navigation:**
```
Server-Einstellungen (linke Seite) 
  → Übersicht (ganz oben)
```

**Was du hier siehst:**
- Server-Name
- Server-Icon (Logo)
- Server-Beschreibung
- AFK-Kanal
- System-Nachrichten-Kanal

**Was du tun musst:**
- Scrolle nach unten bis du **"Community"** siehst
- Klicke auf den blauen Button **"Community aktivieren"**
- Bestätige mit **"Los geht's"**
- Folge dem Setup-Assistenten (3-4 Schritte)

---

### 2.2 Community-Setup-Assistent

**Schritt 1: Sicherheitsanforderungen**
- ✅ Verifizierte E-Mail-Adresse erforderlich
- ✅ 2FA für Moderatoren aktivieren
- Klicke **"Weiter"**

**Schritt 2: Regeln**
- Wähle einen Kanal für Regeln (erstelle #regeln wenn noch nicht vorhanden)
- Oder: **"Später einrichten"**
- Klicke **"Weiter"**

**Schritt 3: Community-Updates**
- Wähle einen Kanal für Updates (z.B. #ankündigungen)
- Oder: **"Später einrichten"**
- Klicke **"Fertig"**

✅ **Community ist jetzt aktiviert!**

---

### 2.3 Moderation einstellen

**Navigation:**
```
Server-Einstellungen (linke Seite)
  → Sicherheit (unter "Moderation")
```

**Was du hier siehst:**
- Verifizierungsstufe
- Expliziter Medieninhalt-Filter
- DM-Spam-Filter

**Empfohlene Einstellungen:**

**Verifizierungsstufe:**
- Klicke auf das Dropdown-Menü
- Wähle: **"Mittel"** (Mitglied muss seit 5 Minuten registriert sein)

**Expliziter Medieninhalt-Filter:**
- Wähle: **"Alle Mitglieder scannen"**

**2FA-Anforderung:**
- Scrolle nach unten
- Aktiviere: **"2FA für Moderator-Aktionen erforderlich"**

Klicke unten rechts auf **"Änderungen speichern"** (grüner Button)

---

### 2.4 Willkommensbildschirm

**Navigation:**
```
Server-Einstellungen (linke Seite)
  → Community (unter "Community")
  → Willkommensbildschirm
```

**Was du hier siehst:**
- Aktivieren/Deaktivieren Toggle
- Willkommensnachricht bearbeiten
- Willkommenskanäle auswählen

**Einstellungen:**
1. Toggle oben rechts auf **"Aktiviert"** (blau)
2. **Willkommensnachricht:** (Optional, kann leer bleiben)
3. **Willkommenskanäle:** Wähle #willkommen und #regeln
4. Klicke **"Änderungen speichern"**

---

### 2.5 Mitglieder-Verifizierung

**Navigation:**
```
Server-Einstellungen (linke Seite)
  → Sicherheit
  → Mitglieder-Verifizierung
```

**Was du hier siehst:**
- Verifizierungsstufe einstellen
- Regeln müssen akzeptiert werden

**Einstellungen:**
1. Toggle auf **"Aktiviert"**
2. **Verifizierungsstufe:** Mittel (10 Minuten Wartezeit)
3. **Regeln-Kanal:** Wähle #regeln
4. Klicke **"Änderungen speichern"**

---

## 📁 Schritt 3: Kanäle erstellen

### 3.1 Kategorie erstellen

**So geht's:**
1. Rechtsklick auf deinen Server-Namen (oben links)
2. Klicke auf **"Kategorie erstellen"**
3. Name eingeben: z.B. `📋 WILLKOMMEN & INFO`
4. Klicke **"Kategorie erstellen"**

**Oder:**
1. Klicke auf das **"+"** neben "Textkanäle" oder "Sprachkanäle"
2. Wähle **"Kategorie"**
3. Name eingeben
4. Klicke **"Kategorie erstellen"**

---

### 3.2 Textkanal erstellen

**So geht's:**
1. Rechtsklick auf die **Kategorie** (z.B. "WILLKOMMEN & INFO")
2. Klicke auf **"Kanal erstellen"**
3. Wähle **"Text"** (sollte schon ausgewählt sein)
4. **Kanal-Name:** z.B. `willkommen` (Discord fügt automatisch # hinzu)
5. **Kanal-Thema:** (Optional) Kurze Beschreibung
6. Klicke **"Kanal erstellen"**

**Emoji im Namen:**
- Einfach Emoji kopieren und vor den Namen setzen
- Beispiel: `📢-willkommen`

---

### 3.3 Kanal-Berechtigungen ändern

**Beispiel: #willkommen (nur lesen, nicht schreiben)**

1. Rechtsklick auf den Kanal **#willkommen**
2. Klicke auf **"Kanal bearbeiten"**
3. Gehe zu **"Berechtigungen"** (linke Seite)
4. Klicke auf **"Berechtigung hinzufügen"**
5. Wähle **"@everyone"** (die Standard-Rolle)
6. Scrolle zu **"Nachrichten senden"**
7. Klicke auf das **rote X** (verbieten)
8. **"Nachrichten lesen"** sollte auf **grünem Haken** bleiben
9. Klicke unten rechts auf **"Änderungen speichern"**

✅ Jetzt können alle lesen, aber niemand schreiben!

---

### 3.4 Ankündigungs-Kanal erstellen

**Für #ankündigungen:**

1. Erstelle den Kanal wie oben beschrieben
2. Rechtsklick → **"Kanal bearbeiten"**
3. Gehe zu **"Übersicht"** (linke Seite)
4. Scrolle nach unten
5. Aktiviere **"Ankündigungskanal"** (Toggle)
6. Klicke **"Änderungen speichern"**

**Berechtigungen setzen:**
- @everyone: Nachrichten senden = ❌ (rotes X)
- @everyone: Nachrichten lesen = ✅ (grüner Haken)
- Nur du kannst posten!

---

### 3.5 Forum-Kanal erstellen

**Für #feedback-ideen oder #bug-reports:**

1. Rechtsklick auf Kategorie → **"Kanal erstellen"**
2. Wähle **"Forum"** (statt Text)
3. Name eingeben: z.B. `feedback-ideen`
4. Klicke **"Kanal erstellen"**

**Vorteile:**
- Jeder Beitrag wird automatisch ein Thread
- Übersichtlicher für Diskussionen
- Kann mit Tags organisiert werden

---

## 👥 Schritt 4: Rollen erstellen

### 4.1 Rollen-Menü öffnen

**Navigation:**
```
Server-Einstellungen (linke Seite)
  → Rollen (unter "Benutzerverwaltung")
```

**Was du hier siehst:**
- Liste aller Rollen
- @everyone (Standard-Rolle)
- Button "Rolle erstellen"

---

### 4.2 Neue Rolle erstellen

**So geht's:**
1. Klicke auf **"Rolle erstellen"** (oben rechts)
2. Es erscheint eine neue Rolle "neue Rolle"

**Rolle bearbeiten:**

**Tab "Anzeige":**
- **Rollen-Name:** z.B. `Moderator`
- **Rollen-Farbe:** Klicke auf das Farbfeld → Wähle Farbe (z.B. #00F593 für Grün)
- **Rollen-Icon:** (Optional) Emoji hochladen
- **Rolle separat anzeigen:** ✅ Aktivieren (zeigt Rolle in Mitgliederliste)

**Tab "Berechtigungen":**
- Scrolle durch die Liste
- Aktiviere benötigte Berechtigungen (grüner Haken)

**Für Moderator:**
- ✅ Nachrichten verwalten
- ✅ Mitglieder kicken
- ✅ Mitglieder bannen
- ✅ Mitglieder in Timeout versetzen
- ✅ Kanäle verwalten

**Tab "Mitglieder verwalten":**
- Hier kannst du später Mitglieder zur Rolle hinzufügen

Klicke unten rechts auf **"Änderungen speichern"**

---

### 4.3 Rollen-Hierarchie

**Wichtig:** Rollen weiter oben haben mehr Macht!

**Reihenfolge ändern:**
1. In der Rollen-Liste (Server-Einstellungen → Rollen)
2. **Ziehe die Rollen** mit der Maus nach oben/unten
3. Empfohlene Reihenfolge (von oben nach unten):
   - 👑 Owner (deine Rolle)
   - 🛡️ Moderator
   - 💻 Entwickler
   - 🎮 Streamer
   - 🐛 Bug Hunter
   - ⭐ Early Supporter
   - ✅ Verifiziert
   - 🆕 Neuling
   - @everyone (immer ganz unten)

---

### 4.4 Rolle einem Mitglied geben

**So geht's:**
1. Rechtsklick auf ein **Mitglied** (in der Mitgliederliste rechts)
2. Klicke auf **"Rollen"**
3. Wähle die Rolle aus (z.B. "Moderator")
4. Klicke außerhalb des Menüs → Fertig!

**Oder:**
1. Server-Einstellungen → Rollen
2. Wähle die Rolle (z.B. "Moderator")
3. Tab **"Mitglieder verwalten"**
4. Klicke **"Mitglieder hinzufügen"**
5. Suche das Mitglied
6. Klicke auf den Namen → Fertig!

---

## 🤖 Schritt 5: Bots hinzufügen

### 5.1 MEE6 hinzufügen

**So geht's:**
1. Öffne im Browser: https://mee6.xyz
2. Klicke oben rechts auf **"Login"**
3. Melde dich mit Discord an
4. Klicke auf **"Add to Discord"**
5. Wähle deinen Server aus dem Dropdown
6. Klicke **"Autorisieren"**
7. Bestätige mit **"Ich bin kein Roboter"**

✅ MEE6 ist jetzt auf deinem Server!

**MEE6 konfigurieren:**
1. Gehe zu: https://mee6.xyz/dashboard
2. Wähle deinen Server
3. Linke Seite: Verschiedene Module
   - **Leveling:** Aktivieren
   - **Welcome:** Aktivieren (Willkommensnachricht)
   - **Moderator:** Aktivieren (Auto-Moderation)

---

### 5.2 GitHub Bot hinzufügen

**So geht's:**
1. Öffne im Browser: https://github.com/apps/discord
2. Klicke auf **"Install"**
3. Wähle dein GitHub-Konto
4. Wähle **"Only select repositories"**
5. Wähle **"StreamMatrix"**
6. Klicke **"Install"**

**In Discord verbinden:**
1. Gehe in deinen Discord-Server
2. Gehe in den Kanal **#github-updates**
3. Tippe: `/github subscribe 19bounty9317/StreamMatrix`
4. Drücke Enter
5. Der Bot antwortet mit einer Bestätigung

✅ Jetzt bekommst du automatisch Updates von GitHub!

---

## 🔗 Schritt 7: Einladungslink erstellen

### 7.1 Link erstellen

**So geht's:**
1. Rechtsklick auf deinen **Server-Namen** (oben links)
2. Klicke auf **"Einladen"**
3. Es öffnet sich ein Fenster mit einem Link

**Oder:**
1. Klicke auf das **Dropdown-Menü** neben dem Server-Namen
2. Klicke auf **"Freunde zum Server einladen"**

---

### 7.2 Link-Einstellungen anpassen

**Im Einladungs-Fenster:**
1. Klicke unten auf **"Link bearbeiten"** oder **"Erweitert"**

**Einstellungen:**
- **Ablaufdatum:** Wähle **"Nie"** (Link läuft nie ab)
- **Max. Nutzungen:** Wähle **"Keine Begrenzung"**
- **Temporäre Mitgliedschaft:** **Aus** (Mitglieder bleiben dauerhaft)

2. Klicke auf **"Link generieren"**
3. Klicke auf **"Kopieren"**

✅ Link ist in deiner Zwischenablage!

**Link sieht so aus:**
```
https://discord.gg/ABC123XYZ
```

## 💡 Häufige Probleme

**Problem: "Ich finde Server-Einstellungen nicht"**
- Lösung: Rechtsklick auf Server-Namen → "Server-Einstellungen"
- Oder: Klick auf Server-Namen oben → Dropdown-Menü

**Problem: "Ich kann keine Kategorie erstellen"**
- Lösung: Du brauchst Admin-Rechte. Bist du der Server-Owner?

**Problem: "MEE6 antwortet nicht"**
- Lösung: Warte 1-2 Minuten. Bot braucht Zeit zum Starten.

**Problem: "GitHub Bot funktioniert nicht"**
- Lösung: Stelle sicher, dass der Bot die Berechtigung hat, in #github-updates zu schreiben
