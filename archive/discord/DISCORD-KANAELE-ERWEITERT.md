### ❓ faq
**Typ:** Text (nur lesen)

```
❓ **Häufig gestellte Fragen (FAQ)**

**Q: Ist StreamMatrix kostenlos?**
A: Ja! 100% kostenlos und Open Source (GPL-3.0 Lizenz).

**Q: Warum zeigt Windows eine Sicherheitswarnung?**
A: Code-Signatur-Zertifikate kosten 300€/Jahr. Als kostenloses Projekt nicht finanzierbar. 
→ Klicke auf "Weitere Informationen" → "Trotzdem ausführen"
→ Die App ist sicher! Open Source = jeder kann den Code prüfen.

**Q: Funktioniert es mit OBS?**
A: Ja! StreamMatrix kann mit OBS verbunden werden (experimentell).

**Q: Welche Daten werden gespeichert?**
A: Alle Daten werden lokal auf deinem PC gespeichert. Keine Cloud, kein Tracking, keine Datenübermittlung.

**Q: Kann ich eigene Themes erstellen?**
A: Aktuell gibt es 5 vordefinierte Themes. Custom Themes sind für die Zukunft geplant!

**Q: Unterstützt es andere Plattformen (YouTube, Kick)?**
A: Aktuell nur Twitch. Andere Plattformen sind geplant.

**Q: Wie kann ich helfen?**
A: GitHub Issues, Pull Requests, Feedback, Bug Reports, Tutorials - alles hilft!

**Q: Gibt es eine mobile App?**
A: Nein, nur für Windows Desktop. Mobile Version ist nicht geplant.

**Weitere Fragen?** → <#hilfe>
```
