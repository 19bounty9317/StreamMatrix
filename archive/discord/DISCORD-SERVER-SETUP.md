# 🎮 StreamMatrix Discord Server - Komplettes Setup

## 📋 Schritt 1: Server erstellen (2 Minuten)

1. Discord öffnen → Klicke auf das **"+"** links
2. **"Eigenen erstellen"** → **"Für eine Community"**
3. **Server-Name:** `StreamMatrix`
4. **Server-Icon:** Lade `docs/logo.png` hoch
5. **Fertig!** ✅

---

## 🎨 Schritt 2: Server-Einstellungen (3 Minuten)

**Server-Einstellungen → Übersicht:**
- ✅ Community-Server aktivieren
- ✅ Willkommensbildschirm aktivieren
- ✅ Mitglieder-Verifizierung aktivieren (10 Minuten Wartezeit)

**Server-Einstellungen → Moderation:**
- ✅ Verifizierungsstufe: Mittel
- ✅ Expliziter Medieninhalt-Filter: Alle Mitglieder scannen
- ✅ 2FA-Anforderung für Moderatoren

**Server-Einstellungen → Community:**
- ✅ Regeln-Kanal: #regeln
- ✅ Community-Updates-Kanal: #ankündigungen

---

## 📁 Schritt 3: Kategorien & Kanäle erstellen (10 Minuten)

- Berechtigungen: Alle können lesen, niemand kann schreiben

**Q: Ist StreamMatrix kostenlos?**
A: Ja! 100% kostenlos und Open Source.

**Q: Warum zeigt Windows eine Sicherheitswarnung?**
A: Code-Signatur-Zertifikate kosten 300€/Jahr. Klicke auf "Weitere Informationen" → "Trotzdem ausführen". Die App ist sicher!

**Q: Funktioniert es mit OBS?**
A: Ja! StreamMatrix kann mit OBS verbunden werden.

**Q: Welche Daten werden gespeichert?**
A: Alle Daten werden lokal auf deinem PC gespeichert. Keine Cloud, keine Tracking.

**Q: Kann ich eigene Themes erstellen?**
A: Aktuell gibt es 5 vordefinierte Themes. Custom Themes sind geplant!

**Q: Wie kann ich helfen?**
A: GitHub Issues, Pull Requests, Feedback, Bug Reports - alles hilft!
