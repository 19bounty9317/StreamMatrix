## Über StreamMatrix

StreamMatrix ist eine moderne, leistungsstarke Desktop-Anwendung, die speziell für Twitch-Streamer entwickelt wurde. Mit einem intuitiven, anpassbaren Dashboard behältst du während deines Streams alles im Blick - von Chat-Nachrichten über Follower-Benachrichtigungen bis hin zu detaillierten Stream-Statistiken.

**Entwickelt mit modernsten Technologien:**
- Electron für native Desktop-Performance
- React für eine flüssige, reaktive Benutzeroberfläche
- TypeScript für maximale Code-Qualität
- Twitch API Integration für Echtzeit-Daten

---

## Hauptfunktionen

### 🎮 Live Chat Integration
- Echtzeit-Chat mit Emote-Unterstützung (Twitch, BTTV, FFZ, 7TV)
- Moderations-Tools: Timeout, Ban, Nachrichten löschen
- Slow Mode & Emote-Only direkt steuerbar
- Farbcodierte Badges und Benutzernamen

### 📊 Stream-Statistiken
- Live Viewer-Zahlen und Peak-Tracking
- Follower- und Subscriber-Zähler
- Stream-Historie mit Kalenderansicht
- Detaillierte Session-Statistiken

### 🎯 Aktivitätsfeed
- Echtzeit-Benachrichtigungen für Follows, Subs, Raids
- Bits und Channel Points Redemptions
- Hype Train Events
- Anpassbare Event-Animationen

### 🎨 Anpassbares Dashboard
- Drag & Drop zum Umordnen von Kacheln
- 16+ verschiedene Kachel-Typen
- Kompakt-Modus für mehr Übersicht
- 8 vordefinierte Themes (Twitch Dark, Purple Dream, Neon Nights, etc.)

### 🪟 Multi-Window Support (NEU in v1.4.4)
- Öffne Kacheln in separaten Fenstern
- Perfekt für Multi-Monitor-Setups
- Verschiebe Kacheln per Kontextmenü zwischen Fenstern
- Automatisches Zurückverschieben beim Schließen

### 🔧 Quick Actions
- Schnellzugriff auf wichtige Funktionen
- Raid-Ziele mit Live-Vorschau
- OBS-Integration (optional)
- Stream-Einstellungen direkt anpassen

### 🎭 Moderations-Tools
- UserCard mit vollständigen Mod-Funktionen
- Warn-System für Zuschauer
- Profil-Ansicht direkt in der App
- Bestätigungsdialoge für kritische Aktionen

## Technische Details

### System-Anforderungen
- **Betriebssystem:** Windows 10/11 (64-bit)
- **RAM:** Mindestens 4 GB (8 GB empfohlen)
- **Festplatte:** 200 MB freier Speicherplatz
- **Internet:** Stabile Verbindung für Twitch API

### Sicherheit & Datenschutz
- OAuth 2.0 Authentifizierung über Twitch
- Keine Speicherung von Passwörtern
- Lokale Datenspeicherung (keine Cloud)
- Open Source - vollständig transparent

### Updates
- Automatische Update-Benachrichtigungen
- Delta-Updates für schnellere Downloads
- Changelog direkt in der App
- Keine Unterbrechung während des Streams

## FAQ

**Q: Ist StreamMatrix kostenlos?**
A: Ja, StreamMatrix ist komplett kostenlos und Open Source.

**Q: Funktioniert es mit OBS?**
A: Ja, StreamMatrix bietet optionale OBS-Integration über WebSocket.

**Q: Kann ich eigene Themes erstellen?**
A: Aktuell sind 8 vordefinierte Themes verfügbar. Custom Themes sind für zukünftige Versionen geplant.

**Q: Werden meine Daten in der Cloud gespeichert?**
A: Nein, alle Daten werden lokal auf deinem Computer gespeichert.

**Q: Unterstützt StreamMatrix andere Plattformen außer Twitch?**
A: Aktuell nur Twitch. Weitere Plattformen sind in Planung.

**Q: Wie oft wird StreamMatrix aktualisiert?**
A: Regelmäßige Updates mit neuen Features und Bugfixes. Die App benachrichtigt dich automatisch.
