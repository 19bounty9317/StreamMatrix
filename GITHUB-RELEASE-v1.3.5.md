# 🚀 StreamMatrix v1.3.5 - User-Card & Stream-Qualität

## ✨ Was ist neu?

### 👤 User-Card im Chat
Klicke auf einen Usernamen im Chat und erhalte sofort alle wichtigen Infos - genau wie im Twitch Chat!

**Features:**
- 🖼️ Profilbild & Bio
- 📅 Account-Alter
- 👥 Follower-Anzahl
- ⚡ Schnellaktionen: Mod, VIP, Timeout, Ban
- 🔗 Direkter Link zum Twitch-Kanal

### 📊 Stream-Qualität Live-Überwachung
Behalte deine Stream-Qualität im Blick mit Echtzeit-Daten!

**Anzeige:**
- 📡 **Bitrate** - Echt von OBS oder geschätzt von Twitch
- 📉 **Dropped Frames** - Absolut & Prozent
- 🎨 **Farbcodierung** - Grün (gut), Gelb (mittel), Rot (Probleme)

## 🔧 Technische Verbesserungen

- **StreamQualityService** - OBS-Integration für präzise Daten
- **OBSService** - Neue `getStreamStats()` Methode
- **Automatischer Fallback** - Funktioniert auch ohne OBS
